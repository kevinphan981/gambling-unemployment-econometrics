# Gambling-on-Unemployment-DiD

## About
Initially was the final project/paper for ECON 427 (Econometrics II), but will be continued until I feel satisfied. The paper implements an event study design (Sun and Abraham 2021) in order to investigate the effects of the staggered legalization of sports betting on unemployment. The paper is written in LaTeX, which will probably be added here later. I have it on Overleaf, so I'll have to download the zip file eventually.

## Status
The paper is tentatively finished, I cannot think of anything else to adjust or change (other than possible typos and formatting). I will also release a PDF of the paper in this repo as well as on another site.
